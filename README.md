# Tagline

Keeps AGENTS.md updated with the tagline for each source file. This greatly helps coding agents as they don't
have to grep as much.

## Example

```markdown
<!-- BEGIN FILE INDEX -->
## File Index

Autogenerated from first-line comments. Run update_tagline.py to refresh.

- `.github/workflows/ci.yml`: Verify code quality and generated file indexes.
- `README.md`: Tagline
- `pyproject.toml`: Project and tooling configuration for Tagline.
- `update_tagline.py`: Update AGENTS.md files (containing a file index marker) with an auto-generated index.
<!-- END FILE INDEX -->
```
